Recipe — pipelines that know where they’ll break.

We watched an AI agent’s document toolbox for 48 hours. Pandoc emitted a package the image did not have; conversions exited 0 while writing nothing; one tool’s -quality flag was ignored for every value we passed it; the opener command silently launched a GUI that never closed. This app turns those traps into a scoring oracle: build a pipeline, and the page tells you where it will break before you run it.
