Recipe — pipelines that know where they’ll break.

We watched an AI agent’s document toolbox for 48 hours. Conversions exited 0 while writing nothing; one tool’s -quality flag was ignored for every value we passed it; a converter renamed a file instead of converting it; an extractor read strings no pixel ever showed. This studio turns those traps into a scoring oracle that lives on another origin: build a pipeline, run it for real, and the page can only report what the oracle could verify.
